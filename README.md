## **제목: AI의 미래와 지속가능발전**

### **특강 목차 (정리본)**

1. **지구에 소풍 온 나**
   ― 우주 속의 지구, 신비로운 인체, 그리고 ‘나’라는 존재
   *(지속가능발전의 출발점: 생명과 공존)*

2. **정신문화의 수도 안동**
   ― 전통·신앙·교육이 함께 만든 지속가능한 도시의 뿌리

3. **자랑스러운 대한민국의 길**
   ― 산업과 발명, 그리고 일상 속으로 들어온 인공지능

4. **인공지능의 역사와 원리**
   ― AI는 왜 ‘생각하는 것처럼’ 보이는가

5. **AI 실습 체험**
   ― 지속가능한 삶을 돕는 AI 직접 사용해 보기
   *(ChatGPT · KakaoGPT · NotebookLM)*

6. **AI의 미래와 지속가능발전(SDGs)**
   ― 기술의 발전보다 중요한 사람의 선택과 책임
   *(AI의 미래: IBM 관점 반영)*

7. **결론**
   ― AI 시대, 지속가능한 사회를 위해 우리가 해야 할 역할

---

### ✔️ 구성의 핵심 흐름

* **나(인간) → 지역(안동) → 국가(대한민국) → 기술(AI) → 체험 → 미래(SDGs) → 시민의 역할**
* AI를 **기술 설명의 대상**이 아니라
  **지속가능한 삶을 돕는 도구**로 인식하도록 설계
* 60대 학습자에게
  *부담 없는 이해 → 공감 → 체험 → 성찰* 구조
